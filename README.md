# Rebel Routine

面向 HarmonyOS 的本地任务、行动记录与成长管理应用。使用 ArkTS 和 ArkUI 开发，以 P5R 风格呈现每日安排、长期委托和五维成长。

**版本：1.0.0 源码基线。** 本仓库仅包含应用代码、构建配置和功能回归脚本，不包含图片、SVG、字体、研究素材或安装包。克隆后需自行补齐界面资源才能完整构建。

## 功能

| 页面 | 功能 |
| --- | --- |
| 今日 | 快速添加事项、固定模板、复用昨日安排、今日完成与逾期处理、专注计时 |
| 任务 | 按待处理、今天、未来、未安排分组；批量完成、编辑和删除；委托与重复计划 |
| 记录 | 按实际行动日期回看、补记、编辑、日期与来源筛选、委托达成记录、便签 |
| 成长 | 知识、灵巧、魅力、体贴、健康五维段位与称号，查看对应行动来源 |

- **委托**：一次完成、累计次数、数量或时长目标，以及父子项目；支持按周累计、阶段与达成奖励。
- **重复计划**：按每日或指定星期生成独立事项，支持暂停与继续；应用刷新时补生成，不依赖后台调度。
- **便签**：独立随笔，或关联一条事项、历史行动或委托；支持搜索、回收与恢复。
- **数据保护**：回收站、完整 JSON 备份与恢复、撤回恢复、CSV 导出、旧版数据迁移。

## 使用逻辑

1. 在「今日」安排今天要做的事，或通过固定模板快速加入。
2. 在「任务」安排未来事项，设置委托和重复计划。
3. 完成事项后，按实际完成日期进入「记录」；有关联委托时同步推进进度。
4. 根据行动配置、阶段或委托达成结果结算成长；在「成长」查看称号和行动来源。
5. 用便签补充感受，用数据管理导出完整备份。

事项的安排日期与实际完成日期分别保存。固定模板、重复计划和生成的事项独立；修改模板不会重写已有事项。删除、恢复和编辑已完成行动会联动调整奖励与委托进度。

CSV 用于查看记录，不能替代完整 JSON 备份恢复。便签不直接给予成长或推进委托。

## 技术架构

- ArkTS + ArkUI，Stage 模型，单个 `entry` 模块。
- 目标 SDK 与兼容 SDK 均为 `6.1.1(24)`；构建使用 Hvigor，依赖由 OHPM 管理。
- `Index` 为页面宿主，`RoutineState` 共享状态，`PageActions` 协调各业务操作。
- 数据命令生成候选快照，统一进行委托结算、校验和事务保存；保存成功后才更新界面。
- 使用 ArkData 关系数据库保存完整 JSON 快照；旧 Preferences 数据迁移前保留原值备份。
- 人格维度自动识别由本地关键词规则实现，当前未接入远程 AI、账号或云同步。

```text
AppScope/                     应用信息与文字资源
entry/src/main/ets/
  entryability/               生命周期入口
  pages/                      页面宿主与统一提交
  views/                      页面与辅助工作区
  components/                 表单、列表、弹窗与视觉控件
  common/                     状态、查询、操作协调、主题与窗口适配
  data/                       模型、命令、结算、校验与本地存储
entry/src/main/resources/     文字、颜色和页面配置
hvigor/                       构建配置
tools/visual-check/           基于实际源码的功能回归脚本
```

## 本地构建

1. 安装支持 HarmonyOS API 24 的 DevEco Studio，并安装匹配的 SDK。
2. 用 DevEco Studio 打开仓库根目录，配置本机 SDK 路径并同步 OHPM 依赖。
3. 补齐下面两个目录中的界面素材，或提供同名替代资源：
   - `AppScope/resources/base/media/`
   - `entry/src/main/resources/base/media/`
4. 在 DevEco Studio 执行 HAP 构建。若需安装到设备，配置自己的签名信息。

资源名称由 `app.json5`、`module.json5` 和源码中的 `$r('app.media.…')` 引用确定；所有 media 素材（包括 SVG）均未上传。当前配置引用 `app_icon_p5` 和 `start_icon_p5`，缺少这些资源同样会阻止构建。本地 SDK 路径、签名证书和私钥不应提交。

安装依赖也可在已经配置 OHPM 的终端中执行：

```powershell
ohpm install
```

## 功能回归

脚本读取真实应用源码，在 Node 中执行业务命令和操作协调逻辑；SDK I/O、时钟及 UI 挂载被替换，不依赖图片素材。这些检查不等于设备持久化或原生渲染验收。

设置 SDK 路径后，使用 DevEco Studio 随附的 Node 执行：

```powershell
$env:DEVECO_SDK_HOME = 'C:\path\to\DevEco Studio\sdk'
& 'C:\path\to\DevEco Studio\tools\node\node.exe' tools/test.cjs
```

SDK 需包含 `default/openharmony/ets/build-tools/ets-loader/node_modules/typescript`。检查覆盖：事项与导航、维度选择、委托和重复计划、便签、删除恢复、原生日期选择器调用，以及迁移、备份、保存失败和事务回滚。

## 当前边界

- 专注计时为 25 分钟内存计时器，支持暂停和重置；尚未保存截止时间，不保证后台或进程重启恢复。
- 专注结束提供反馈，尚未自动生成行动记录、完成关联事项或登记委托时长。
- 数据采用全量快照读写；大量历史记录和便签的性能尚未建立基准。
- 导航通过共享状态切换页面和工作区，尚未引入独立路由栈。
- 新建操作、执行计时与周期复盘的体验优化属于后续迭代，不影响本版本已有功能范围。
