# Rebel Routine

把每天的安排变成任务，把长期目标变成委托，把实际行动积累成成长。

Rebel Routine 是一款受《女神异闻录 5 皇家版》（Persona 5 Royal）启发的 HarmonyOS 任务与个人成长管理应用。它将 P5R 的日程、委托与五维成长融入现实生活，记录你打算做什么，也记录你真正做了什么。

**本地存储 · 无需账号 · 五维成长 · ArkTS / ArkUI**

## 核心功能

- **今日安排**：快速添加事项，通过固定模板或昨日安排组织今天的清单。
- **任务规划**：管理逾期、未来与未安排事项，设置重复计划。
- **长期委托**：以次数、数量、时长或子任务推进目标，设置阶段与达成奖励。
- **行动记录**：按实际完成日期回看行动，也可以补记之前做过的事。
- **五维成长**：积累知识、灵巧、魅力、体贴与健康，查看段位、称号和成长来源。
- **便签与专注**：写独立随笔或关联便签，使用 25 分钟专注计时器。
- **数据管理**：回收站、JSON 备份与恢复、CSV 导出。

## 设计思路

计划和行动有各自的日期。昨天安排的阅读，今天才完成，就记在今天；没有完成的安排也不会被当作成果。

委托把零散行动连接到长期目标。例如，为“本周阅读 120 分钟”登记多次阅读，每次行动都会留下记录，并累计到目标中。完成行动和达成委托可以带来五维成长，成长页也能回到对应的行动来源。

固定模板用于快速复用，重复计划用于持续安排，便签用于留下想法。它们围绕日常行动展开，让安排、执行和回看连在一起。

## 构建与运行

当前版本为 **v1.0 源码版**，尚未提供可直接安装的应用包。公开仓库不包含界面素材；构建前需自行提供同名替代资源。

| 环境 | 项目配置 |
| --- | --- |
| DevEco Studio | 支持 HarmonyOS API 24 的版本；已在本机 API 24 工具链构建 |
| HarmonyOS SDK | 目标与兼容版本均为 `6.1.1(24)` |
| Node.js | 本次验证使用 DevEco Studio 随附的 `18.20.1` |
| 构建与依赖 | Hvigor / OHPM，工程模型版本 `6.1.1` |

1. 克隆仓库：`git clone https://github.com/Ryuuson/RebelRoutine.git`。
2. 在 DevEco Studio 中打开项目，配置 API 24 SDK。
3. 补齐 `AppScope/resources/base/media/` 和 `entry/src/main/resources/base/media/` 下的资源。
4. 同步 OHPM 依赖，构建 HAP；安装到设备前配置自己的签名。

资源清单、完整构建命令和测试入口见 [开发指南](docs/development.md)。

## 技术与数据

应用使用 ArkTS、ArkUI 和 Stage 模型开发，通过 ArkData 保存本地数据。当前无需登录，也没有云同步或远程 AI 服务；维度自动识别使用本地关键词规则。

备份由用户主动导出。JSON 用于完整恢复，CSV 用于查看记录。代码结构和数据流见 [架构说明](docs/architecture.md)。

## 项目状态

核心功能已实现，当前代码已通过本地构建与业务测试。专注计时尚未支持可靠的后台恢复或自动登记行动；最新界面修复仍需真机确认。

后续重点是统一事项操作、简化表单、关联专注与行动，以及增加周期回顾。详细限制、验证记录和后续方向见 [项目状态](docs/project-status.md)。
