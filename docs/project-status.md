# 项目状态

## v1.0

目前提供 v1.0 源码，核心功能包括今日安排、事项管理、行动记录、五维成长、委托、重复计划、便签和本地备份。尚未发布可直接安装的应用包。

## 已知限制

- 专注计时是内存中的 25 分钟计时器，支持暂停与重置；尚未保存截止时间，后台或进程重启后不能保证恢复。
- 专注结束提供反馈，尚未自动生成行动记录、完成事项或登记委托时长。
- 重复事项依赖应用内刷新补生成，未接入系统后台调度。
- 数据采用全量快照读写，大量历史记录和便签的性能尚未建立基准。
- 主页面与工作区通过共享状态切换，尚未引入独立路由栈。
